# EON Focus Finder

A standalone ranked view of the 788-company EON portfolio for commercial focus prioritization. Fully independent — no server, no shared backend.

- **Live page:** https://aafadar-git.github.io/eon-focus-finder/
- `index.html` — the full Finder page (self-contained; data embedded)
- `focus-dataset.json` — the source dataset and system of record: 788 enriched company records with transparent 0–100 scores, enrichment fields, and training-leader contacts. The page renders from this file; updating it updates the page.
- Ask EON: bring-your-own-key Q&A over the dataset (the key stays in the visitor's browser)

Built October 2026. Ranking derived from internal trigger-event data; enrichment and contacts from public web research.
