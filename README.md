# EON Focus Finder

Ranked commercial-intelligence view of the 788-company EON portfolio — a static companion to the internal Streamlit app.

- **Live page:** enable GitHub Pages on this repo (Settings → Pages → Deploy from branch → `main`, `/(root)`) and it serves at `https://<owner>.github.io/eon-focus-finder/`
- `index.html` — the full Finder page (self-contained; data embedded)
- `focus-dataset.json` — the source dataset: 788 enriched company records with transparent 0–100 scores, enrichment fields, and training-leader contacts

Built October 2026. Internal Wingman trigger data underlies the ranking.
